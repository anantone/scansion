    module Scansion

    Module principal du gem scansion : scansion (syllabification) des vers français — phonétisation espeak-ng via phonemizer_ffi, alignement lettres/phonèmes, restauration du e muet, diérèses contextuelles et comptage des syllabes. Voir docs/scansion_rules.txt pour les règles. Points d’entrée : Scansion.process_line, Scansion.process_lines, Scansion.espeak.

    Constants

    Aligner

    État mutable de l’alignement d’UN mot orthographique sur les segments phonétiques (voir align_word). Un Struct pour que les méthodes step partagent et modifient l’index de lettre / le curseur de segments sans longue liste de paramètres. step renvoie true (lettre consommée, on continue), :done (arrêt : alignement réussi tôt — terminaison muette alors que les segments sont épuisés) ou false (alignement impossible → le vers entier retombe sur espeak brut).

    CONSONANT_DIGRAPHS
    CONSONANT_LETTERS
    CR_E_PRONOUNCED

    Exceptions à la règle « -Cr- + e muet » (docs/scansion_rules.txt 1.5d) : dans ces mots, le e final EST prononcé devant une consonne (astre -> as-tʁə, entendre -> ɑ̃-tɑ̃-dʁə, entre -> ɑ̃-tʁə, être -> ɛ-tʁə, guerre -> gɛ-ʁə, maître -> mɛ-tʁə, moindre -> mwɛ̃-dʁə, œuvre -> œ-vʁə, ventre -> vɑ̃-tʁə…), contrairement à arbre -> aʁbʁ, mettre -> mɛtʁ, fièvre -> fjɛvʁ. Devant une voyelle ou en fin de vers, l’élagage normal s’applique toujours (élision / non compté).

    DIGRAPH_ALT

    digrammes qu’espeak-ng peut rendre par un phone alternatif

    DIGRAPH_ONE_PHONE

    digrammes de voyelles prononcés comme un seul noyau syllabique, associés au nombre de voyelles (lettres) qu’espeak-ng émet pour eux (absorber la 2e lettre ; ne pas la laisser manger la voyelle du mot suivant : ou entendre ; ui -> yi)

    ENT_TAIL

    la terminaison après le e de la désinence verbale -ent : « nt » / « nts »

    E_MUET_TAIL

    ce qui peut suivre un e muet quasi final avant la terminaison muette : « s » (tables), « ts » (sifflets), « ps », « x » (silex), ou rien (Philippe)

    FINAL_DEVOICE

    dévoisement final tel que le rend espeak-ng (Austerlitz -> …lits)

    GLIDE_PHONE
    H_ASPIRE

    Petite liste de mots fréquents à h aspiré (correspondance par préfixe : « hisser » couvre aussi hissera, hissons, hissé…). Un mot à h aspiré est PHONÉTIQUEMENT à initiale vocalique (le h est muet : « hasard » -> /a-zaʁ/) mais BLOQUE l’élision/la liaison du mot précédent : « le hasard » -> lə-a-zaʁ, jamais *la-zaʁ ; « se hisser » -> sə-i-se, jamais *sise. À contraster avec le h muet : « l’homme » -> lɔm (élision). Voir h_aspiré? / elides_before?.

    LIAISON_FINAL

    consonne finale prononcée avec sa valeur de liaison devant une voyelle (les amis -> lɛzami, quand il -> kɑ̃til, grand ami -> gʁɑ̃tami…)

    LIAISON_LETTERS

    lettres dont la consonne finale fait liaison devant un mot à initiale vocalique (elle reste donc l’ATTAQUE de la syllabe suivante : les amis -> lɛ-za-mi)

    NEXT_VOWELISH

    lettres voyelles par lesquelles un mot SUIVANT peut commencer, pour le test du « e oral » dans elidable_final_e? (remet à -> ʁəmɛta n’est pas une élision)

    Result

    Résultat de la scansion d’un vers (voir Scansion.process_line / Scansion.process_lines) :

    • text : vers d’origine ;

    • raw : sortie IPA brute d’espeak-ng ;

    • phones : syllabes séparées par « - » (ex. “la-bɛl-ta-blə-ʁɔ̃d”) ;

    • syllables : nombre de syllabes comptées ;

    • aligned : true si l’alignement lettres/phonèmes a réussi (false = repli

      sur la sortie brute d'espeak-ng, voir #fallback?) ;

    • dierese : nombre de diérèses appliquées ;

    • word_spans : pour chaque mot, { word:, first:, last: } = indices de ses

      syllabes dans +phones+ (nil en repli non aligné).
    SCHWA
    SILENT_TAILS
    SILENT_TAIL_LIST

    Suites de lettres finales qui peuvent rester non prononcées une fois tous les segments phonétiques consommés. Toute autre chose fait échouer l’alignement (repli sur la sortie brute). Liste littérale (SILENT_TAIL_LIST) pour rester lisible ; l’expression régulière en est déduite. Ancrage aux deux extrémités, donc l’ordre des alternatives est sans importance.

    SOFT_NEXT
    STABLE_SCHWA

    Monosyllabes grammaticaux à « e fixe » (schwa stable, NON caduc) : jamais élidés devant une consonne, même en mode contemporain — « le passé » -> lə-pa-se (jamais lpa-se), « que me veux-tu » -> kə-mə-vø-ty. Ils ne s’élident que devant une voyelle (élision : « l’ami », « qu’amer »).

def classical_context?(counts, idx, window: 5, threshold: 0.7)
  lo = [idx - window, 0].max
  hi = [idx + window, counts.size - 1].min
  neigh = counts[lo..hi].compact
  neigh.delete_at(idx - lo) if idx >= lo && idx <= hi
  return false if neigh.empty?
  # bande alexandrine 10-13 (11/13 = candidats diérèse) OU bande
  # octosyllabe 6-9 (les 7 y sont des candidats diérèse)
  neigh.count { |c| (10..13).cover?(c) || (6..9).cover?(c) }.to_f / neigh.size >= threshold
end

    Détection de contexte de poésie classique : true quand les lignes voisines (fenêtre autour de idx) tombent majoritairement dans la bande alexandrine 10-13 ou la bande octosyllabe 6-9 (11/13 et 7 y sont des candidats diérèse/surcompte, donc ils appartiennent à la bande). La diérèse ne peut être inférée que dans un contexte aussi régulier — JAMAIS en poésie contemporaine (samples/), où elle ne peut pas être déduite d’un nombre de syllabes cible. counts : décomptes de syllabes par ligne (nil pour les lignes vides ou non alignées).

def clean_ipa(raw)
  raw.to_s.gsub(/\([a-z]{2,3}\)/i, "")
           .gsub(/[\uFEFF\u200B-\u200D\u00AD]/, "")
           .gsub(/[\s\"()_ˈˌ‿ːˑ|[[:punct:]]]/, "")
           .tr("ɡɹθðɪʌæɒ", "gʁtdiaaɔ")
end

    Nettoie le flux IPA brut : supprime les marqueurs de changement de langue d’espeak-ng « (en) »/« (fr) » EN ENTIER — ne retirer que les parenthèses laisserait des segments parasites « en »/« fr » qui cassent l’alignement (qu’hier -> (en)kwhˈiə(fr)). Puis supprime espaces, accents de stress, marques de liaison ET ponctuation : espeak-ng garde « , » (et parfois « . ») dans le flux IPA, alors que words_of() la supprime, donc un segment « , » parasite casserait l’alignement. Supprime aussi les caractères de largeur nulle/BOM, normalise U+0261 en g ASCII, et « dé-anglicise » l’API anglaise d’espeak (ɹ→ʁ, θ→t, ð→d, ɪ→i, ʌ→a, æ→a, ɒ→ɔ : rythme, macbeth, punch).

def cli_phonemize(line)

def cluster_re_pronounced?(word, on)
  w = word.sub(/s\z/, "") # tolérance pour le pluriel en -s (pauvres, gloires…)
  on && (w.end_with?("re") || w.match?(/[cgq]u?e\z/))
end

    En contexte classique (dierese actif), le e final d’un mot en -Cre (consonne + r + e : notre, vivre, âpre, spectre, meurtre, centre, pauvre, ivre, ombre, sombre, décembre…) est COMPTÉ — no-tre, vi-vre, â-pʁə, mœʁ-tʁə… La règle 1.5d (e muet après -Cr- jamais compté) est une règle de prononciation moderne : elle ne s’applique qu’en mode contemporain (dierese: false / –no-dierese). En contexte classique, le e final de tout mot en -re est COMPTÉ (notre -> no-tʁə, vivre -> vi-vʁə, mais aussi -ère/-oire/-ire : mère -> mè-re, chère -> chè-re, gloire -> gloi-re, terre -> ter-re…). on = false en mode contemporain, true sinon (ou ciblage cluster_words).

def compute_scan_line(line, dierese: false, dierese_words: nil, cluster_words: nil,
                      ent_words: nil, pause_e: false, count_mute_e: false)
  # normalise une fois pour que words_of et espeak voient les mêmes lettres
  clean = normalize_input(line)
  words = words_of(clean)
  if words.empty?
    return Result.new(text: line, raw: "", phones: "",
                      syllables: 0, aligned: true, dierese: 0)
  end

  raw = espeak(clean)
  segs = segments(raw)

  words_out = []
  cursor = 0
  aligned = true

  words.each_with_index do |w, k|
    res = align_word(w, segs, cursor,
                     next_vowel_initial: liaison_initial?(words[k + 1].to_s),
                     next_word: words[k + 1],
                     prev_fragment: k.positive? &&
                       %w[c j l d n s t m qu].include?(words[k - 1]),
                     dierese: dierese, dierese_words: dierese_words,
                     cluster_words: cluster_words, ent_words: ent_words,
                     count_mute_e: count_mute_e)
    if res.nil?
      aligned = false
      break
    end
    words_out << { word: w, pairs: res[0] }
    cursor = res[1]
  end
  aligned &&= (cursor == segs.size)

  unless aligned
    # repli sûr : sortie brute d'espeak, sans restauration
    syll = count_syllables(segs)
    return Result.new(text: line, raw: raw, phones: mark_syllables(segs),
                      syllables: syll, aligned: false, dierese: 0)
  end

  # élagage de scansion des schwas finaux restaurés
  paused = pause_flags(clean, words)
  words_out.each_with_index do |w, k|
    pairs = w[:pairs]
    next unless pairs.last && pairs.last[0] == SCHWA

    next_word = (words_out[k + 1] || {})[:word]
    # un e final PRONONCÉ (CR_E_PRONOUNCED, ou -Cre en contexte classique)
    # reste compté même devant une pause : « ivre, complice » -> i-vʁə (2)
    pronounced = cr_e_pronounced?(w[:word]) ||
                 cluster_re_pronounced?(w[:word],
                                        cluster_words ? cluster_words.include?(w[:word]) : dierese)
    if next_word.nil?                # fin de vers : e muet non compté
      pairs.pop
    elsif elides_before?(next_word) && !plural_mute_e?(w[:word])
      pairs.pop # élision devant une voyelle / un h muet (sauf pluriel -es/-eux : e prononcé)
    elsif paused[k] && !pronounced && !pause_e
      pairs.pop # devant une pause (, ; : ! ? …) ; pause_e : e compté (alexandrine)
    elsif !dierese && !pause_e && !count_mute_e && !pronounced &&
          !stable_schwa?(w[:word])
      # mode contemporain (--no-dierese) : l'e CADUC n'est jamais compté
      # devant une consonne (« mes pères criaient » -> pɛʁ, 8 syllabes) ;
      # en contexte classique (dierese/:auto, pause_e) il reste compté.
      # Exception : le schwa des monosyllabes grammaticaux (le, de, me,
      # te, se, que, ne, je, ce) est un « e fixe » — jamais élidé devant
      # une consonne (« le passé » -> lə-pa-se, 8 syllabes et non 7)
      pairs.pop
    end
  end

  flat = []
  barriers = []
  words_out.each_with_index do |w, k|
    barriers << [flat.size, words[k - 1], paused[k - 1]]
    w[:pairs].each { |ph, _| flat << ph }
  end
  phones = mark_syllables(flat, barriers)
  syllables = count_syllables(flat, barriers)

  dier = words_out.sum do |w|
    w[:pairs].count { |ph, restored| restored && %w[i u].include?(ph) }
  end

  # spans mot -> indices de syllabes (pour les outils en aval, ex.
  # scansion/accents) : même règle de comptage que count_syllables
  # (un glide y/ɥ suivi d'une voyelle n'est pas un noyau, sauf si la
  # voyelle ouvre le mot suivant)
  word_spans = []
  syl = 0
  words.each_with_index do |w, k|
    start = barriers[k][0]
    fin = k + 1 < barriers.size ? barriers[k + 1][0] : flat.size
    first = syl
    (start...fin).each do |fk|
      ph = flat[fk]
      next unless ph[0].match?(VOWEL_PHONE)
      nxt = flat[fk + 1]
      if (ph[0] == "y" || ph[0] == "ɥ") && nxt && nxt[0].match?(VOWEL_PHONE) &&
         !(k + 1 < barriers.size && barriers[k + 1][0] == fk + 1)
        next
      end
      syl += 1
    end
    word_spans << { word: w, first: first, last: syl - 1 }
  end
  Result.new(text: line, raw: raw, phones: phones,
             syllables: syllables, aligned: aligned, dierese: dier,
             word_spans: word_spans)
end

def context_meter(counts, idx, window: 5, threshold: 0.7)
  lo = [idx - window, 0].max
  hi = [idx + window, counts.size - 1].min
  neigh = counts[lo..hi].compact
  neigh.delete_at(idx - lo) if idx >= lo && idx <= hi
  return nil if neigh.empty?
  meters = neigh.select { |c| METER.include?(c) }
  return nil if meters.size.to_f / neigh.size < threshold
  meters.tally.max_by { |_k, v| v }&.first
end

    Mètre dominant du contexte (vers voisins) : la valeur de METER la plus fréquente parmi les voisins, si elle est majoritaire (>= 70 %). Sert à « tirer » un vers contemporain régulier vers le mètre du poème (ex. octosyllabe : un vers de 7 tire l’e caduc pour faire 8).

def count_syllables(phones, barriers = [])
  word_starts = barriers.map { |b| b[0] }
  count = 0
  phones.each_with_index do |ph, k|
    next unless ph[0].match?(VOWEL_PHONE)
    if (ph[0] == "y" || ph[0] == "ɥ") && phones[k + 1] &&
       phones[k + 1][0].match?(VOWEL_PHONE) &&
       !word_starts.include?(k + 1)
      next
    end
    count += 1
  end
  count
end

    Décompte des syllabes : chaque phone voyelle compte, SAUF un glide rendu « y » (ɥ) directement suivi d’une voyelle — fuyait -> f-yi-jɛ fait 2 syllabes, pas 3 (le y est le glide de « ui », pas un noyau) barriers = débuts de mots dans phones (voir mark_syllables) : un glide y/ɥ suivi d’une voyelle n’est un glide (non compté) que si la voyelle appartient AU MÊME mot (fuyait -> f-yi-jɛ = 2) ; entre deux mots c’est un hiatus et le y est le noyau /y/ compté (étendue où -> …-dy-u = 2)

def cr_mute_final_e?(word, i, dierese = false)
  i >= 2 && word[i - 1] == "r" && !word[i - 2].match?(VOWEL_LETTER) &&
    word[(i + 1)..].to_s.match?(/\A(?:x)?\z/) && !cr_e_pronounced?(word) &&
    !cluster_re_pronounced?(word, dierese)
end

def elidable_final_e?(word, i, head, out, next_vowel_initial, next_word, dierese = false)
  return false unless final_e_before_vowel?(word, i, head, out, next_vowel_initial)
  return false if next_word && y_glide?(next_word) # pas d'élision devant /j/
  # un e FINAL en -Cr- (sombre, mettre — terminaison vide/x, PAS avant un
  # s muet) est muet même devant un h aspiré (sombre héros ->
  # sɔ̃-bʁe-ʁo), donc ne jamais le restaurer comme élision ; la branche
  # -Cr- de step_vowel s'en charge. Les mots en -es (propres airs ->
  # pʁɔ-pʁə-zɛʁ) gardent leur e via la règle 1.5. CR_E_PRONOUNCED
  # (voir cr_e_pronounced?) exempté.
  return false if cr_mute_final_e?(word, i, dierese)
  return false if %w[e ɛ].include?(head[0]) && !head.match?(/̃/) &&
                  next_word.to_s.match?(NEXT_VOWELISH)
  true
end

    Forme longue (ajoute la garde du « e oral ») : le e muet est vraiment élidé par espeak-ng parce que le mot suivant est à initiale vocalique, donc on restaure un schwa ici (l’élagage de scansion le retire ensuite). PAS une élision quand la tête est un e/ɛ ORAL que le mot suivant ne peut pas produire : c’est la voyelle propre de ce mot (remet à -> ʁəmɛta) ; un ɛ̃ nasal appartient au mot suivant (encore informe -> …kɔʁɛ̃f…). PAS non plus une élision pour les mots en -Cr- à e muet (sombre, mettre) : leur e est muet de toute façon, même devant un h aspiré (sombre héros -> sɔ̃-bʁe-ʁo, pas sɔ̃-bʁə-…) ; CR_E_PRONOUNCED (voir cr_e_pronounced?) est exempté.

def espeak(line)
  line = normalize_input(line)
  raw = phonemizer_ffi(line)
  raw = phonemizer_gem(line) if raw.nil?
  raw = cli_phonemize_safe(line) if raw.nil?
  raw = espeak_ng(line) if raw.nil?
  clean_ipa(raw.to_s)

def main(argv = ARGV)
  options = { syllables_only: false, dierese: :auto }
  OptionParser.new do |opts|
    opts.banner = "Utilisation : #{File.basename($PROGRAM_NAME)} [options] [FILE|-]"
    opts.on("--no-dierese", "Désactiver la diérèse contextuelle (corpus contemporain)") do
      options[:dierese] = false
    end
    opts.on("-s", "--syllables", "Afficher seulement le décompte des syllabes") do
      options[:syllables_only] = true
    end
    opts.on("-h", "--help", "Afficher cette aide") do
      puts opts
      exit
    end
  end.parse!(argv)

  Encoding.default_external = Encoding::UTF_8

  fallbacks = 0

  # Accepte des chemins de fichiers ou du texte de vers en argument :
  #   scansion poeme.txt
  #   scansion "Au coin du feu, dans la langueur des rêveries!"
  inline = []
  ARGV.replace(argv.flat_map do |arg|
    if arg == "-" || File.exist?(arg)
      arg
    else
      inline.concat(arg.split(/[\r\n]+/))
      nil
    end
  end.compact)

  lines =
    if inline.any? && ARGV.empty?
      inline.each
    elsif inline.any?
      # mélange de texte en ligne et de chemins de fichiers : traiter
      # d'abord les lignes passées en ligne
      Enumerator.new do |y|
        inline.each { |l| y << l }
        ARGF.each_line { |l| y << l }
      end
    else
      ARGF.each_line
    end

  lines = lines.to_a.map(&:chomp)
  process_lines(lines, dierese: options[:dierese]).each do |res|
    next if res.text.strip.empty?

    if options[:syllables_only]
      puts format("%3d  %s", res.syllables, res.text.to_s.strip)
    else
      puts res.text.to_s.rstrip
      puts format("  %s %s   (%d syll.)", res.aligned ? "⇒" : "~", res.phones, res.syllables)
      puts "    (espeak seul : #{res.raw})" unless res.aligned
      puts ""
    end

    fallbacks += 1 unless res.aligned
  end

  warn "scansion : #{fallbacks} vers non alignés (sortie espeak brute)" if fallbacks.positive?
end

def mark_syllables(phones, barriers = [])
  cuts = {}
  prev_vowel = nil
  phones.each_with_index do |ph, k|
    next unless ph[0].match?(VOWEL_PHONE)
    # un glide y/ɥ suivi d'une voyelle n'est pas un noyau (même règle que
    # count_syllables) : il ne déclenche aucune coupure de syllabe
    # glide seul (segment d"une seule lettre) suivi d"une voyelle : pas un noyau
    # (un segment comme « yi » a son noyau dans la voyelle qui suit le glide)
    next if ph.length == 1 && (ph[0] == "y" || ph[0] == "ɥ") &&
            phones[k + 1] && phones[k + 1][0].match?(VOWEL_PHONE)
    if prev_vowel
      cut = nil
      inside = barriers.select { |b, _| b > prev_vowel && b < k }
      if inside.any?
        cut = inside.first[0]
      elsif (info = barriers.find { |b, _| b == k })
        prev_word, prev_paused = info[1].to_s, info[2]
        unless %w[l j].include?(prev_word) ||
               (!prev_paused && LIAISON_LETTERS.include?(prev_word[-1].to_s))
          cut = k # coda du mot précédent, coupure à la frontière
        end
      end
      if cut.nil?
        cluster = phones[(prev_vowel + 1)...k].map { |p| p[0] }.join
        onset = cluster.size.downto(1).find do |len|
          valid_onset?(cluster[-len..], cluster.size >= 3)
        end || 0
        cut = k - onset
      end
      cuts[cut] = true
    end
    prev_vowel = k
  end
  out = +""
  phones.each_with_index do |ph, k|
    out << "-" if cuts[k] && !out.empty?
    out << ph
  end
  out
end

    Insère un séparateur « - » à chaque frontière de syllabe dans une liste de segments phonétiques. barriers = [index, mot_précédent, pause_précédente] pour chaque début de mot. Règles :

    - un cluster de consonnes chevauchant une frontière de mot est coupé
  À la première frontière (la consonne finale du mot précédent devient
  coda : mer en -> mɛʁ-ɑ̃, par moi -> paʁ-mwa, l'envol est -> vɔl-ɛ...);
- exception : une lettre de liaison devant un mot à initiale vocalique
  reste l'attaque (les amis -> lɛ-za-mi), sauf si une pause la bloque
  (inutiles, enfant -> til-ɑ̃), et les articles élidés l'/j' fusionnent
  (l'abstinente -> lab-sti...);
- sinon, le tiret va devant le plus long cluster d'attaque VALIDE
  (per-clus -> pɛʁ-kly, re-tourne -> ʁə-tuʁn).

    Une coda finale ne reçoit pas de séparateur ; un hiatus (pas de consonne) est coupé.

def pause_flags(line, words)
  toks = line.downcase.gsub(/&[a-zA-Z#0-9]+;/, " ")
             .scan(/([a-zà-ÿœ]+)([^a-zà-ÿœ\s]*)/u)
  flags = toks.map { |_w, tail| tail.match?(/[.,;:!?…—]/) }

def process_line(line, dierese: false, cache: nil)
  # en mode :auto, la 1re passe garde le comptage classique de l'e muet
  # devant consonne (sinon elle pourrait tomber sur 10 et arrêter là) ;
  # en mode plain direct (--no-dierese), l'e muet n'est pas compté.
  r = scan_line(line, dierese: false, cache: cache,
                count_mute_e: dierese != false)
  if dierese == true
    r = scan_line(line, dierese: true, cache: cache)
  elsif dierese == :auto && r.aligned && !METER.include?(r.syllables)
    # 1) diérèse globale + e des -re comptés (contexte classique)
    r2 = scan_line(line, dierese: true, cache: cache)
    r = r2 if r2.aligned && METER.include?(r2.syllables)
    # 1b) e muet prononcé devant une pause graphique (, ; : ! ? …),
    #     UNIQUEMENT si le vers devient alexandrin (12) : en vers
    #     irrégulier ou contemporain, la pause silencie le e muet
    if !METER.include?(r.syllables)
      r2b = scan_line(line, dierese: false, pause_e: true, cache: cache)
      r = r2b if r2b.aligned && r2b.syllables == 12
    end
    if !METER.include?(r.syllables)
      r2c = scan_line(line, dierese: true, pause_e: true, cache: cache)
      r = r2c if r2c.aligned && r2c.syllables == 12
    end
    # 2) e des -re comptés, aucune diérèse
    if !METER.include?(r.syllables)
      r3 = scan_line(line, dierese: true, dierese_words: [], cache: cache)
      r = r3 if r3.aligned && METER.include?(r3.syllables)
    end
    # 3) ciblage mot à mot : diérèse sur w seul (e des -re tous comptés),
    #    puis diérèse + e de -re sur w seul
    if !METER.include?(r.syllables)
      fix_candidate_words(line).each do |w|
        combos = [[w, nil, nil], [w, [w], nil]]
        combos << [w, nil, [w]] if w.end_with?("ent")
        combos.each do |dw, cw, ew|
          r4 = scan_line(line, dierese: true, dierese_words: dw,
                         cluster_words: cw, ent_words: ew, cache: cache)
          if r4.aligned && METER.include?(r4.syllables)
            r = r4
            break
          end
        end
        break if METER.include?(r.syllables)
      end
    end
  end
  r
end

def process_lines(lines, dierese: :auto)
  cache = {}
  counts = lines.map do |l|
    next nil if l.strip.empty?
    r = scan_line(l, dierese: false, cache: cache, count_mute_e: true)
    r.aligned ? r.syllables : nil
  end
  lines.each_with_index.map do |l, i|
    d = case dierese
        when :auto then (classical_context?(counts, i) ? :auto : false)
        else dierese
        end
    r = process_line(l, dierese: d, cache: cache)
    # vers contemporain régulier (--no-dierese) : si le compte plain ne
    # tombe pas sur un mètre mais que les vers voisins sont unanimes sur
    # un mètre M, compter l'e caduc (sans diérèse) pour atteindre M —
    # « les gouttes du dernier envol » -> 8 dans un poème d'octosyllabes
    if d == false && r.aligned && !METER.include?(r.syllables)
      m = context_meter(counts, i)
      if m
        r2 = scan_line(l, dierese: false, cache: cache, count_mute_e: true)
        r = r2 if r2.aligned && r2.syllables == m
      end
    end
    r
  end
end
